# dot_files
Various configuration files etc.

It is separated in three main sections:
- *Common* - Linux and Windows relevant:
    - vim
    - ssh
    - vscode
    - qutebrowser
- *Linux* specific
    - bash
    - x11 settings
- *Windows* specific:
    - PowerShell
    - WindowsTerminal

> *Update*: I excluded the ones that have sync option within the app (e.g.
> vscode) and the ones that have separate repositories (e.g. PowerShell
> modules).
